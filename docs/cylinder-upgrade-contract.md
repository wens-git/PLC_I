# 气缸升级实施契约（1.3）

本文件是本次源码实现的跨端契约；不代表已完成PLC编译或现场验收。

- 协议 revision 1.3，signature 0x584A5633（1481266739），保持区32/输入区1830 WORD不变。
- cylinder_config仍8 WORD：wiring_flags, move_y, home_y, move_x, home_x, delay_ms, timeout_ms, home_delay_ms。最后字段替代旧未开放的flags。
- delay_ms是动点/吸附确认延时；home_delay_ms是原点/释放确认延时；timeout_ms是动作开始后的总超时。延时0..65534，超时1..65535，两侧延时都必须小于超时。无传感器的一侧延时必须>0。
- 参数提交掩码：delay_ms=1, timeout_ms=2, home_delay_ms=4。前五字段工程只读，禁止上位机修改。
- wiring_flags bit0..1模式：0单线圈弹簧复位，1双线圈保持，2真空吸附（释放关闭吸气），3真空吸附+破真空（释放输出在释放完成后关闭）。bit2动点输入反相，bit3原点输入反相，bit4..15必须0。类型0/2不允许原点输出映射；类型1/3需要原点输出映射。
- move_x/home_x=65535表示该侧无传感器：动作开始后计时确认，绝不可伪造物理传感器；否则实际传感器持续有效达到该侧延时后确认。输入反相仅作用于存在的传感器。
- 无传感器的完成只在本次相应请求成功后成立；启动、取消、故障、反向请求清除时间完成状态。原始传感器状态与请求完成分开。
- 保持现有summary bit0动点确认/bit1原点确认/bit2运动/bit3故障；bit4不再用作调试屏蔽，应为0。HMI根据配置显示“传感器确认”或“延时完成”，真空显示吸附/释放。
- 所有模式到动点保持动点输出；到原点关闭动点输出，类型1保持原点输出，类型3原点输出仅在释放动作中有效。42取消撤销两输出，清除本次完成；故障源消失且明确42时可确认历史故障，不能自动重试。
- 全部物理气缸默认仍未绑定。新增工程表是类型/映射的单一来源，未接线65535；调用者按核验过的映射连接输入/输出，不能把工程绑定位当作真实模块在线反馈。
- PLC统一请求入口：手动Modbus40/41/42与自动中文函数接口共享同一驱动和许可，只有一次请求受理后才可能Done。请求取消/模式切换不得自动重放旧请求。停止优先。连续扫描的新请求也必须可靠执行（不能仅靠Execute BOOL上升沿）。
- 自动接口：气缸_到动点(缸号)、气缸_到原点返回UDINT请求号（0为未提交）；气缸_忙/完成/故障查询同时传入缸号和请求号，避免其他来源完成被误认；另有气缸_取消。新增qualified_only气缸编号GVL，示例夹紧缸常量不等于启用物理绑定。
- 暂停保持取消与42撤销输出不同：暂停取消已发/未发自动请求、清除无感完成与Moving，恢复不重放；类型3暂停关闭破真空输出，不无限吹气。新动作重新计时，单线圈回原/真空释放即使两输出均FALSE也是有效计时起点。旧接线字段由工程表覆盖，禁止未经核验继承旧bit4/5。
- 暂停/停止与夹持安全：暂停禁止新动作并取消自动流程完成资格，输出保持需明确工程策略；软/硬急停与显式取消处理必须一致且文档说明不是物理安全回路。默认未绑定不驱动；不要未经配置把所有夹持缸暂停时释放。
- 升级保持区：不得因签名改变清空已有轴/点位参数；从旧0x584A5632识别迁移，只将旧气缸flags替换为delay_ms，保留轴点位，清配置确认，要求重新核验。模拟持久化按版本迁移或明确拒绝损坏，不静默误用。
