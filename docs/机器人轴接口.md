# 机器人轴接口

业务程序在单一控制任务内调用，轴号为 0..15，槽号为共享点位池的 0..119。
轴 i 的 P0 是槽 i；不存在每轴独立的“第 16 点”编号。

```iecst
CASE i步骤 OF
    0:
        IF Axis_MoveToPoint(0, 16) THEN
            i步骤 := 10;
        ELSE
            i步骤 := 900;
        END_IF;
    10:
        IF Axis_Done(0) THEN
            i步骤 := 20;
        ELSIF Axis_Error(0) THEN
            i步骤 := 900;
        END_IF;
END_CASE;
```

`Axis_MoveToPoint(轴号, 槽号)`、`Axis_Home(轴号)` 返回 TRUE 仅表示已提交，
不是许可通过或运动完成。调用一次后等待，不要每扫描重复调用。
`Axis_Stop(轴号)` 可以抢占本接口的请求，也可停止该轴的其他动作。

`Axis_Done(轴号)` 是本接口最近一次运动成功完成的锁存状态。
新请求立即清除 Done；停止、拒绝、故障和取消不置 Done。
`Axis_Busy(轴号)` 表示本接口有待处理或执行中的请求，不等价于物理轴正在运动。
`Axis_Error(轴号)` 表示最近请求被拒绝、失败或取消；非法轴号返回 TRUE。
错误数字可在 `全局变量_轴请求.ast请求[轴号].w错误` 在线观察，含义沿用拒绝码；
19 表示取消或下发结果不确定。轴驱动故障详情仍查看运行时轴状态。

每轴只有一个请求，忙时提交新普通请求返回 FALSE，原请求继续；调用方必须处理
这个返回值。不同轴可并行。每轴只能由一个业务流程拥有，函数不提供多流程锁。
请求、完成状态和序列均不保持，上电不重放。

服务端每扫描先处理网络请求，再处理每轴内部请求，共用命令结构校验、
唯一动作许可、点位读取、额定值和限位校验。内部请求不改网络 SEQ/ACK 纪元。
参数在受理时锁定；修改点位不会改变正在执行的目标。

自动请求要求正式流程接入、HMI 在线、运行中、未暂停、无需复位，
以及现有安全和轴许可条件。源程序中的正式流程和安全验收开关仍关闭。
不应通过伪造手动模式或在线状态绕过这些条件，不增加保持区运动门禁。

在主循环中，业务流程应在服务端之前提交请求。暂停恢复在服务端之后编排，
物理轴之后执行请求监视。暂停、退出运行、复位、断线或急停取消当前运动，
恢复后由业务步骤显式重新提交；没有自动重放。

PLC 编译、隔离仿真逻辑测试和真机验收是不同证据。模拟反馈自测不证明 MC
运动、接线、独立安全链或现场停车距离。
