# 硬件 IO 对照表与气缸接线方法

当前采用**直连模式**：少量气缸全接 PLC 内建 X/Y，一套信号一个命名 BOOL，由输入/输出映射程序直接接进驱动；扩展模块才走映像（点号从 32 起）。物理地址只出现在 [全局变量_物理IO.gvl.st](../plc/src/hardware/全局变量_物理IO.gvl.st)。

## 1. 直连接线模板

| 气缸 | 信号 | 变量（`AT` 地址） | 端子 | 工程表点号 |
|---|---|---|---|---|
| CY00 | 动点传感器 | `bCY00_动点传感器 AT %IX0.5` | X5 | 5 |
| CY00 | 原点传感器 | `bCY00_原点传感器 AT %IX0.6` | X6 | 6 |
| CY00 | 动点阀 | `bCY00_动点阀 AT %QX0.2` | Y2 | 2 |
| CY00 | 原点阀 | `bCY00_原点阀 AT %QX0.3` | Y3 | 3 |
| CY01 | 动点传感器 | `bCY01_动点传感器 AT %IX0.7` | X7 | 7 |
| CY01 | 原点传感器 | 不接（工程表用 `Cy确认.延时`） | — | 65535 |
| CY01 | 动点阀 | `bCY01_动点阀 AT %QX0.6` | Y6 | 6 |
| CY01 | 原点阀 | `bCY01_原点阀 AT %QX0.7` | Y7 | 7 |

固定按钮/安全点：X0 启动 `b启动按钮`、X1 暂停 `b暂停按钮`、X2 复位 `b复位按钮`、X3 急停 `b急停按钮`、X4 备用 `b备用输入`。  
轴占用（禁止用于气缸）：Y0/Y1 轴脉冲、Y4/Y5 轴方向；若启用轴2/轴3，Y6/Y7 会被方向占用，与模板冲突。  
未使用的内建点（以后加缸时按需声明，`%IX/%QX` 地址需实测）：X10～X13、Y10～Y13。

## 2. 增加一个气缸：只改 3 个地方

1. **接线声明** [全局变量_物理IO.gvl.st](../plc/src/hardware/全局变量_物理IO.gvl.st)：加 `bCYxx_动点传感器 AT %IX...`、`bCYxx_动点阀 AT %QX...` 等；
2. **映射程序**：在 [程序_气缸输入映射.st](../plc/src/hardware/程序_气缸输入映射.st) 末尾加 `ab气缸动点传感器[i] := bCYxx_动点传感器;`，在 [程序_气缸输出映射.st](../plc/src/hardware/程序_气缸输出映射.st) 末尾加 `bCYxx_动点阀 := ab气缸动点输出[i];`；
3. **工程表** [全局变量_气缸工程.gvl.st](../plc/src/hardware/全局变量_气缸工程.gvl.st)：加一行（点号 = 端子号，见下例），并把 `已绑定` 改为 TRUE。

```st
(* CY00：X5/X6 传感器，Y2/Y3 阀；双电控 *)
(已绑定 := TRUE, e阀型 := Cy阀型.双线圈保持,
 out动点 := 2, out原点 := 3,
 e动点确认 := Cy确认.传感器, in动点 := 5,
 e原点确认 := Cy确认.传感器, in原点 := 6),
```

改完重新编译下载即可；HMI 手动按钮、状态、超时/故障逻辑都不用动。

## 3. 扫描顺序（[程序_主循环.st](../plc/src/entry/程序_主循环.st)）

```
气缸绑定 → 输入快照 → 服务端 → 模式 → 轴组
→ 气缸输入映射（扩展映像 + 直连传感器）→ 气缸调度
→ 气缸输出映射（扩展映像 + 直连阀）→ 发布
```

- `ab气缸动点传感器[]/输出[]` 是驱动的按缸号接口；
- 映射程序末尾那几行就是"命名端子 ↔ 缸号"的绑定，改线只改那里和上面的物理声明；
- 工程表点号只用于 HMI 显示与配置校验，必须和接线表一致。

## 4. 扩展模块（可不用，点号从 32 起）

1. XS Studio 设备树加扩展输入/输出模块，总线任务 `EtherCAT_Task`；
2. 输入模块映射到 `aw气缸输入映像[2]` 起（点 32 起；word0/word1 不用，最多到 `[6]`）；
3. 输出模块映射到 `aw气缸输出映像[2]` 起（点 32 起，最多到 `[3]`）；
4. 模块诊断 → `b气缸输入模块在线` / `b气缸输出模块在线`；
5. 编译下载并核验后，在 [全局变量_运行配置.gvl.st](../plc/src/hardware/全局变量_运行配置.gvl.st) 置 `b气缸IO已接入 := TRUE`（或 `b气缸IO模块诊断已接入 := TRUE`）；默认 FALSE，未改前气缸一律离线。

## 5. 极性与滤波

HSIO 配置页（一般输入滤波）与 SDFCfg0 软元件配置页（`X*_Logic`/`Y*_Logic` 正负逻辑、`Filter_Time_1..4`）都可用，但必须遵守：

1. 同一信号只在一个地方取反：SDFCfg0 设了负逻辑，工程表就不要再设 `动点反相/原点反相`；
2. 滤波只留一层：硬件滤波和 `功能块_输入滤波` 软件滤波不要重复叠加；
3. 两张配置页的滤波值可能不一致（HSIO 20000us 与 SDFCfg0 默认 10ms），以实测为准；
4. 急停等安全信号仍由现场硬回路保证，本程序不是安全 PLC。

## 6. 工程表校验规则

- 类型 0/2 的 `out原点` 必须留 65535；类型 1/3 必须有且≠`out动点`；
- 同缸 `in动点`≠`in原点`；两个已绑定缸的输入点不得重复，输出点不得重复（DI/DO 各自空间，可同号）；
- `Cy确认.延时` 的一侧省略输入；无传感器侧延时必须 > 0，两侧延时都小于总超时；
- 工程表点号必须与接线表一致（HMI 显示/校验用）；换线时改物理声明、映射程序、工程表三处。

## 7. 常见气缸配置示例（5 种）

以下示例都把点号当端子号用，**未接线前保持 `已绑定 := FALSE`**。CY02～CY04 用到 X10/Y10 以后的内建点，`%IX/%QX` 地址首次使用前必须实测确认。延时/超时不在工程表里写，由上位机“气缸参数”弹窗设置（HMI 命令 50）。

### ① CY00 双电控，两端磁性开关（最常用）

```st
(* 物理IO：X5/X6 输入，Y2/Y3 输出 *)
bCY00_动点传感器 AT %IX0.5 : BOOL;
bCY00_原点传感器 AT %IX0.6 : BOOL;
bCY00_动点阀 AT %QX0.2 : BOOL;
bCY00_原点阀 AT %QX0.3 : BOOL;

(* 输入映射末尾 *)
ab气缸动点传感器[0] := bCY00_动点传感器;
ab气缸原点传感器[0] := bCY00_原点传感器;

(* 输出映射末尾 *)
bCY00_动点阀 := ab气缸动点输出[0];
bCY00_原点阀 := ab气缸原点输出[0];

(* 工程表 *)
(已绑定 := TRUE, e阀型 := Cy阀型.双线圈保持,
 out动点 := 2, out原点 := 3,
 e动点确认 := Cy确认.传感器, in动点 := 5,
 e原点确认 := Cy确认.传感器, in原点 := 6),
```

HMI：按钮“到动点/到原点/撤销命令”。注意 42/取消时双线圈阀只是失电保持，**不会停止正在运动的气缸**。

### ② CY01 双电控，原点用时间确认（只有动点开关）

```st
bCY01_动点传感器 AT %IX0.7 : BOOL;   (* X7 *)
bCY01_动点阀 AT %QX0.6 : BOOL;       (* Y6 *)
bCY01_原点阀 AT %QX0.7 : BOOL;       (* Y7 *)

(* 输入映射末尾 *)
ab气缸动点传感器[1] := bCY01_动点传感器;   (* 原点侧不接线，保持 FALSE *)

(* 输出映射末尾 *)
bCY01_动点阀 := ab气缸动点输出[1];
bCY01_原点阀 := ab气缸原点输出[1];

(* 工程表 *)
(已绑定 := TRUE, e阀型 := Cy阀型.双线圈保持,
 out动点 := 6, out原点 := 7,
 e动点确认 := Cy确认.传感器, in动点 := 7,
 e原点确认 := Cy确认.延时),
```

HMI 参数里“原点确认延时”必须 >0；它只是计时完成，**不代表物理到位**。

### ③ CY02 单线圈弹簧复位（推料缸），只有动点开关

```st
bCY02_动点传感器 AT %IX1.0 : BOOL;   (* X10，地址待实测 *)
bCY02_动点阀 AT %QX1.0 : BOOL;       (* Y10，地址待实测 *)

ab气缸动点传感器[2] := bCY02_动点传感器;

bCY02_动点阀 := ab气缸动点输出[2];

(已绑定 := TRUE, e阀型 := Cy阀型.单线圈复位,
 out动点 := 10,
 e动点确认 := Cy确认.传感器, in动点 := 10,
 e原点确认 := Cy确认.延时),
```

单线圈没有原点输出（`out原点` 省略=65535）；回原靠弹簧 + 时间确认。42 断电后弹簧复位，**不是保持位置**。

### ④ CY03 真空吸附（无破真空），吸附开关 + 释放延时

```st
bCY03_真空开关 AT %IX1.1 : BOOL;     (* X11，地址待实测 *)
bCY03_吸气阀 AT %QX1.1 : BOOL;       (* Y11，地址待实测 *)

ab气缸动点传感器[3] := bCY03_真空开关;

bCY03_吸气阀 := ab气缸动点输出[3];

(已绑定 := TRUE, e阀型 := Cy阀型.真空吸附,
 out动点 := 11,
 e动点确认 := Cy确认.传感器, in动点 := 11,
 e原点确认 := Cy确认.延时),
```

HMI 按钮变成“吸附/释放/释放（关吸气）”。类型 2 没有破真空输出；超时或传感器冲突时**保持吸附**并锁存故障，需人工 42 或急停释放。

### ⑤ CY04 真空带破真空，吸附/释放都有传感器，释放检测常闭

```st
bCY04_真空开关 AT %IX1.2 : BOOL;     (* X12，地址待实测 *)
bCY04_释放检测 AT %IX1.3 : BOOL;     (* X13，地址待实测，常闭 *)
bCY04_吸气阀 AT %QX1.2 : BOOL;       (* Y12，地址待实测 *)
bCY04_破真空阀 AT %QX1.3 : BOOL;     (* Y13，地址待实测 *)

ab气缸动点传感器[4] := bCY04_真空开关;
ab气缸原点传感器[4] := bCY04_释放检测;

bCY04_吸气阀 := ab气缸动点输出[4];
bCY04_破真空阀 := ab气缸原点输出[4];

(已绑定 := TRUE, e阀型 := Cy阀型.真空带破真空,
 out动点 := 12, out原点 := 13,
 e动点确认 := Cy确认.传感器, in动点 := 12,
 e原点确认 := Cy确认.传感器, in原点 := 13,
 原点反相 := TRUE),
```

类型 3 的 41 动作会“关吸气 + 开破真空”，释放确认后关破真空；`原点反相 := TRUE` 只在释放检测是常闭/低电平时用，注意不要和 SDFCfg0 的负逻辑重复反相。

### 汇总

| 例 | 阀型 | 输出 | 传感器 | 确认方式 | HMI 特殊点 |
|---|---|---|---|---|---|
| ① CY00 | 双线圈保持 | Y2/Y3 | X5/X6 | 两侧传感器 | 42 不会停住运动 |
| ② CY01 | 双线圈保持 | Y6/Y7 | X7 | 动点传感器 / 原点延时 | 原点延时须>0 |
| ③ CY02 | 单线圈复位 | Y10 | X10 | 动点传感器 / 原点延时 | 42 弹簧回原 |
| ④ CY03 | 真空吸附 | Y11 | X11 | 吸附传感器 / 释放延时 | 超时保持吸附 |
| ⑤ CY04 | 真空带破真空 | Y12/Y13 | X12/X13 | 两侧传感器 | 原点反相、超时保持吸附 |

## 8. 验证与维护

1. **在线监视**：XS Studio 观察 `ab气缸动点传感器[]`、`ab气缸原点传感器[]` 和命名 BOOL；
2. **HMI 限制**：I/O 页只发布内建 X0..X4、Y0/Y1（实际 Y6/Y7）；Y0/Y1 现在显示 CY01 两路阀；
3. **手动测试**：手动模式下点“到动点/到原点/撤销”，验证端位、超时（2140）、传感器冲突（2110）；
4. **改动后**：重新离线重建 PLC 工程（[rebuild_current.py](../plc/tools/rebuild_current.py)）、编译下载，并重新生成构建证据与交付清单；历史 MANIFEST 不得复用。
